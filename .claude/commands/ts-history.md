**Troubleshooting** - Show Session History

Read protocol/skills/ts.md and execute `/ts history` command.

**Displays**:
- Last 30 troubleshooting sessions
- Session ID
- Tier level
- Problem summary
- Resolution status
- Time to resolution
- Agents deployed
- Escalation path

Helps identify recurring issues and troubleshooting patterns.
