## 📦 Component 2: TS Troubleshooting Tier System

**File**: `protocol/skills/ts.md` (828 lines, ~30KB)
**Version**: 1.0.0
**Owner**: Gojo (Mission Control)

### Commands (9)

| Command | Tier | Description |
|---------|------|-------------|
| `/ts_tier1` | Minor bugs | Quick fix (Yuuji + Megumi, 30-45 min) |
| `/ts_tier2` | Moderate bugs | Enhanced investigation (60-90 min) |
| `/ts_tier3` | Complex bugs | Support agent selection (user picks specialists) |
| `/ts_tier4` | Critical bugs | Advanced investigation (root cause diagram, multi-hypothesis) |
| `/ts_codered` | All hands | Mandatory plan mode (9 agents, full doc sync) |
| `/ts_status` | - | Show current session status |
| `/ts_history` | - | Show recent troubleshooting sessions |
| `/ts_escalate` | - | Manual tier escalation |
| `/ts_complete` | - | Close and archive session |

### Tier Progression: Hybrid Model

**Initial Tier Selection**: User selects based on bug severity
- Minor bugs → tier1
- Moderate bugs → tier2
- Complex bugs → tier3
- Critical bugs → tier4
- System-wide failures → codered

**Auto-Escalation**: After 2 failed attempts per tier (configurable)
- Tier1 fails twice → Auto-escalate to tier2
- Tier2 fails twice → Auto-escalate to tier3
- Etc.

**Manual Escalation**: Available anytime via `/ts_escalate`

### Context-Dependent Support Agent Selection (Tier3-4)

User selects specialists based on bug domain:
- **Todo**: Database issues (schema, queries, migrations)
- **Panda**: CI/CD issues (build, deployment, Docker)
- **Maki**: Performance issues (slow queries, memory leaks)
- **Inumaki**: API issues (REST, GraphQL, WebSocket)
- **Nobara**: UX issues (accessibility, user flow)

All recommendations route to Yuuji via `@implementation` handoff.

### Codered Mode (Tier 5)

**Critical Protocol**: All 9 agents deployed
- Mandatory plan mode (recommendation output if not active)
- Full documentation sync (6 files)
- Gojo synthesizes unified recommendation after all-agent findings
- Strategic decision-making at highest level

### State Architecture

**New File**: `.protocol-state/troubleshooting-history.json`
- Session archive with retention policy
- Tracks total sessions, tier distribution, resolution times
- Auto-archive after 90 days (100 session max)

**Updated File**: `.protocol-state/project-state.json`
- Added `troubleshooting_session` schema (current session state)
- Added `troubleshooting_statistics` schema (aggregated metrics)
