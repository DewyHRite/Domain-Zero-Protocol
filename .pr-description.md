## v8.8.0: Session Monitor CLI Complete Interface

This PR enhances the session monitoring system with a complete CLI interface, resolving missing command errors and improving operational procedures for Gojo orchestration.

---

## Problem Statement

Users encountered `Unknown command` errors when trying to use intuitive session commands:
- `new-session` (exit code 1) - Users naturally expect this alias for `start`
- `reset` (exit code 1) - No way to clear session state
- Missing break/resume workflow commands

Gojo's orchestration workflows referenced commands that didn't exist or had incorrect usage patterns.

---

## Solution Overview

### 5 New CLI Commands

1. **`new-session`** - Alias for `start` (matches natural language expectations)
2. **`reset`** - Clear session state with automatic backup
3. **`continue`** / **`resume`** - Resume work after break
4. **`help`** / **`--help`** / **`-h`** - Comprehensive command reference
5. **Enhanced `break`** - Now accepts duration argument
