Complete Setup Guide

Follow these steps to install and configure the Domain Zero Protocol from scratch. Each command includes a copy button for easy execution.

Prerequisites

Before installing Domain Zero Protocol, ensure you have:

  • Node.js v18 or higher installed
  • npm or yarn package manager
  • A terminal or command prompt
  • An Anthropic API key (for Claude access)

Step 1: Install Claude Code CLI

Install the Claude Code command-line interface globally:

Install Claude Code CLI npm install -g @anthropic-ai/claude-code

After installation, authenticate with your Anthropic API key:

Authenticate Claude CLI claude login

Step 2: Install Domain Zero Protocol

Clone the Domain Zero Protocol repository and set up the project structure:

2.1 Clone the Repository

Clone DZP Repository git clone https://github.com/DewyHRite/Domain-Zero-Protocol.git cd Domain-Zero-Protocol

2.2 Install Dependencies

Install Project Dependencies npm install

2.3 Configure Protocol Settings

Open protocol.config.yaml and update the following:

protocol.config.yaml - Minimum Configuration user: name: "Your Name" contact: "your@email.com" technical_level: current: "intermediate" # beginner | intermediate | expert project: name: "Your Project Name" repo: "https://github.com/yourusername/yourrepo" versioning: protocol_version: "9.8.0" last_updated: "2026-01-30"

2.4 Initialize State Directory

Create State Directory mkdir -p .protocol-state mkdir -p .dzp-killswitch

2.5 Copy Protocol Files to Project

Copy Protocol to Your Project cp -r protocol /path/to/your/project/ cp protocol.config.yaml /path/to/your/project/

2.6 Verify Installation

Verify Protocol Files ./scripts/verify-protocol.sh # Linux/Mac # OR ./scripts/verify-protocol.ps1 # Windows PowerShell

Step 3: Configure CLAUDE.md Memory

Set up the global CLAUDE.md file for universal protocol context across all projects:

3.1 Create Global CLAUDE.md Directory

Create ~/.claude Directory mkdir -p ~/.claude

3.2 Create Global CLAUDE.md File

Create ~/.claude/CLAUDE.md with the following optimized content (23,105 characters):

~/.claude/CLAUDE.md - Universal DZP Context # Domain Zero Protocol - Multi-Installation Setup I use the Domain Zero Protocol for AI-assisted development. This is an eight-agent system: - YUUJI (Implementation Specialist): Test-first development, feature implementation - MEGUMI (Security Analyst): OWASP Top 10 security reviews - NOBARA (Creative Strategy & UX): User experience design, product vision - GOJO (Mission Control): Project lifecycle, protocol guardian - TODO (Database & Backend): Schema design, migrations, query optimization - MAKI (Performance): Audits, profiling, zero-overhead optimization - PANDA (Build & Integration): CI/CD, builds, environments - INUMAKI (API & Communication): REST/GraphQL/WebSocket, OpenAPI ## Multi-Installation Architecture **Each project root has its own isolated DZP installation.** Projects outside a root directory have their own independent protocol files, configuration, and state. ## Protocol Files - `protocol/CLAUDE.md` (main protocol, v8.13.0) - `protocol/yuuji.agent.md` (implementation agent) - `protocol/megumi.agent.md` (security agent) - `protocol/nobara.agent.md` (creative strategy agent) - `protocol/gojo.agent.md` (mission control) **Configuration:** `protocol.config.yaml` **State Files:** `.protocol-state/` ## Tier System - Tier 1 (Rapid): Fast prototyping, no tests - Tier 2 (Standard): Production features with TDD + security review [DEFAULT] - Tier 3 (Critical): Enhanced testing + multi-model security review for auth/payments/sensitive data ## Invocation Pattern **From within project directory or subprojects:** ``` "Read protocol/gojo.agent.md" "Read protocol/yuuji.agent.md and [task]" "Read protocol/megumi.agent.md and [review]" "Read protocol/nobara.agent.md and [design]" ``` ## Key Features - Use skills for common operations to save tokens (skill: 'skill-name') - Use AskUserQuestion tool frequently for clarification and nice UI - All agents have escape paths - they will ask for help rather than hang - Centralized state with pointer files in subprojects - Each installation is isolated - no cross-contamination When I say 'Read protocol/[AGENT].agent.md', always read the file first to follow the protocol. The canonical source is: https://github.com/DewyHRite/Domain-Zero-Protocol ## Writing Style: Humanize When writing or editing text: - Vary sentence structures and lengths - Avoid repeated sentence patterns and overused transitions - Eliminate unnecessary clarifications and repetitive phrases - Remove clichés and fluff - Keep writing simple, concise, and meaningful - Do not use em dashes (—) - Preserve original citations, formatting, and main points

The Tier System

Match process rigor to feature criticality. Choose the tier that fits your needs.

🚀 Tier 1: Rapid

Time: 10-15 minutes

Testing: None (fast iteration)

Security Review: Skipped

Use Cases:

  • Prototypes and experiments
  • Learning exercises
  • Throwaway code
  • Quick scripts
Example invocation claude chat --agent yuuji "Read protocol/yuuji.agent.md --tier rapid and create Python script"

⚖️ Tier 2: Standard [DEFAULT]

Time: 30-45 minutes

Testing: Unit tests (TDD)

Security Review: Standard OWASP audit

Use Cases:

  • Production features
  • CRUD operations
  • API endpoints
  • UI components
Example invocation claude chat --agent yuuji "Read protocol/yuuji.agent.md and implement user authentication"

🔒 Tier 3: Critical

Time: 60-90 minutes

Testing: Unit + Integration + E2E

Security Review: Enhanced multi-model audit

Use Cases:

  • Authentication systems
  • Payment processing
  • Medical/legal data
  • Admin privileges
Example invocation claude chat --agent yuuji "Read protocol/yuuji.agent.md --tier critical and implement Stripe payments"

Getting Started (After Setup)

  1. Configure protocol.config.yaml

    Open protocol.config.yaml and replace placeholder values with your project details: your name, contact email, project name, and repository URL.

    Minimum configuration user: name: "Your Name" contact: "your@email.com" project: name: "Your Project Name" repo: "https://github.com/user/repo"

  2. Start Mission Control

    Initialize your session by invoking Gojo. Select Option 1 to resume an existing project or Option 2 to start a new one.

    claude chat --agent gojo "Read protocol/gojo.agent.md"

  3. Implement Features with Yuuji

    Request implementation of features. Yuuji uses test-driven development and follows the tier requirements for your feature type.

    claude chat --agent yuuji "Read protocol/yuuji.agent.md and implement user authentication"

  4. Review Implementation

    Review Yuuji's implementation. Check the code changes, test coverage, and documentation. Approve to proceed or request changes.

  5. Security Audit with Megumi

    For Tier 2 and 3 features, invoke Megumi for security review. She conducts OWASP analysis and identifies vulnerabilities.

    claude chat --agent megumi "Read protocol/megumi.agent.md and review authentication module"

  6. Iterate Until Approved

    If Megumi finds issues, Yuuji fixes them. The cycle continues until Megumi tags @approved with zero security issues.

Key Protocol Files

Understanding the protocol file structure helps you navigate and customize the system.

Protocol files and their purposes
File Purpose
protocol/CLAUDE.md Main protocol documentation. Contains all rules, workflows, and agent specifications. Protected file.
protocol/gojo.agent.md Mission Control agent. Project lifecycle, intelligence reports, protocol enforcement.
