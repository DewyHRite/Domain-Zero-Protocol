What is Domain Zero Protocol?

Zero Defects

The ultimate goal of perfect code: zero security vulnerabilities, zero bugs, zero performance loss, zero technical debt.

Nine Specialized Agents

Each agent brings distinct expertise: implementation, security, UX design, database, performance, build systems, API design, and system updates.

Safety First

User safety and wellbeing override all other objectives. No agent may compromise user safety under any circumstances.

Three-Tier System

Match process rigor to feature criticality: Rapid for prototypes, Standard for production, Critical for sensitive features.

Claude Skills Integration

16 Anthropic skills mapped to all agents: PDF/DOCX/XLSX generation, frontend design, webapp testing, MCP building, and more.

Implementation Routing

Five agents (Nobara, Todo, Maki, Panda, Inumaki) route all code changes through Yuuji, ensuring TDD practices and test coverage.

Domain Zero Protocol creates a bounded space where specialized agents collaborate under absolute protocol authority. When you invoke the protocol, you activate Domain Zero, where the goal is always ZERO: perfect code, zero compromises.

The Three-Tier System

Match process rigor to feature criticality. The tier system ensures you apply the right amount of testing, security review, and documentation for each type of work.

1 Rapid

Rapid Development

For prototypes, experiments, learning exercises, and throwaway code. Fast iteration without formal testing or security review.

  • No tests required
  • No security review
  • Minimal documentation
  • Backups still required
10-15 minutes per feature
Invocation Read yuuji.agent.md --tier rapid and [task]
2 Standard

Standard Development (Default)

For production features, client deliverables, and standard development work. Balanced quality and speed with test-driven development.

  • Unit tests required (TDD)
  • OWASP security review
  • Full documentation
  • Backup and rollback plan
30-45 minutes per feature
Invocation (default) Read yuuji.agent.md and implement [feature]
3 Critical

Critical Development

For authentication, payment processing, sensitive data, and compliance-regulated features. Maximum rigor with enhanced security review.

  • Unit + Integration + E2E tests
  • Enhanced security audit
  • Performance benchmarking
  • Multi-model review (when available)
60-90 minutes per feature
Invocation Read yuuji.agent.md --tier critical and [task]

Getting Started

  1. Configure protocol.config.yaml

    Open protocol.config.yaml and replace placeholder values with your project details: your name, contact email, project name, and repository URL.

    Minimum configuration user: name: "Your Name" contact: "your@email.com" project: name: "Your Project Name" repo: "https://github.com/user/repo"

  2. Start Mission Control

    Initialize your session by invoking Gojo. Select Option 1 to resume an existing project or Option 2 to start a new one.

    Read protocol/gojo.agent.md

  3. Implement Features with Yuuji

    Request implementation of features. Yuuji uses test-driven development and follows the tier requirements for your feature type.

    Read protocol/yuuji.agent.md and implement user authentication

  4. Review Implementation

    Review Yuuji's implementation. Check the code changes, test coverage, and documentation. Approve to proceed or request changes.

  5. Security Audit with Megumi

    For Tier 2 and 3 features, invoke Megumi for security review. She conducts OWASP analysis and identifies vulnerabilities.

    Read protocol/megumi.agent.md and review authentication module

  6. Iterate Until Approved

    If Megumi finds issues, Yuuji fixes them. The cycle continues until Megumi tags @approved with zero security issues.

Key Protocol Files

Understanding the protocol file structure helps you navigate and customize the system.

Protocol files and their purposes
File Purpose
protocol/CLAUDE.md Main protocol documentation. Contains all rules, workflows, and agent specifications. Protected file.
protocol/gojo.agent.md Mission Control agent. Project lifecycle, intelligence reports, protocol enforcement.
protocol/yuuji.agent.md Implementation specialist. Test-first development, feature implementation.
protocol/megumi.agent.md Security analyst. OWASP reviews, vulnerability assessment, security approval.
protocol/nobara.agent.md UX and creative strategy. User experience design, accessibility compliance.
protocol.config.yaml Central configuration. User settings, tier requirements, safety boundaries.
.protocol-state/ State directory. Project state, dev notes, security reviews, research summaries.
.dzp-killswitch/ Emergency stop state. Kill switch status, checkpoints, activation history.
scripts/file-rotate.py File rotation utility. Automatically archives dev-notes.md and security-review.md at 25k characters with SHA-256 verification.
protocol/skills/ Skills directory. AGENT_SKILLS_MAP.yaml maps 16 Anthropic skills to agents; SKILL_REGISTRY.md tracks all active skills.
